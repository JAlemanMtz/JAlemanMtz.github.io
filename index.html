SIIB-Mobil

El Reto: Digitalizar la trazabilidad operativa en campo sin conexión a internet, vinculando físicamente al ganado usando hardware especializado.

La Solución Arquitectónica: Desarrollé una aplicación móvil nativa en Kotlin conectada vía Bluetooth a bastones lectores RFID. Para la distribución corporativa utilicé un despliegue privado en las tablets internas. Implementé Foreground Services para la persistencia de datos y sincronización con el servidor central mediante una Web API en ASP.NET MVC.

Tecnologías: Kotlin, Android SDK, APIs Bluetooth, ASP.NET MVC, SQL Server.

MDM Lite

El Reto: Administrar y asegurar una flotilla de tablets corporativas en campo, evitando la desconfiguración del entorno operativo por parte de los usuarios.

La Solución Arquitectónica: Creación de una plataforma Mobile Device Management (MDM). Programé validación por dirección MAC y configuré "Modo Kiosco" en Android, bloqueando la interfaz para uso exclusivo de la app interna. El sistema monitorea logs y bloquea actualizaciones no autorizadas.

Tecnologías: Kotlin (Device Owner APIs), C#, ASP.NET MVC, Endpoints HTTP.

Plataforma Agroindustrial

El Reto: Escalar y centralizar procesos operativos críticos abarcando decenas de módulos interconectados como logística, compras, y trazabilidad.

La Solución Arquitectónica: Desarrollo colaborativo de un sistema modular en C# y ASP.NET MVC. Participé en la estructuración de la lógica de negocio para módulos clave (Almacén, Compras, Tracker, Establos). Diseñé la base de datos en SQL Server usando Stored Procedures e integré lectura de puertos COM para procesar automáticamente pesajes industriales.

Tecnologías: C#, ASP.NET MVC, JavaScript, SQL Server (T-SQL), Integración COM.

Sistemas Desktop (Marca Blanca)

El Reto: Crear múltiples sistemas administrativos funcionales para diferentes sectores (educación, retail, construcción) sin tener que reescribir la lógica base desde cero cada vez.

La Solución Arquitectónica: Desarrollé una arquitectura base en C# y Windows Forms que funcionó como sistema "Marca Blanca". Esto me permitió desplegar Puntos de Venta (inventarios, costos, permisos) personalizados con la identidad gráfica de clientes como Tikitos y constructoras locales.

Variación Educativa: Esta misma base modular se adaptó para una escuela patrocinada por Grupo LALA, creando un Sistema de Biblioteca con generación de matrículas, inventario de libros y control de préstamos a alumnos.

Tecnologías: C#, Windows Forms, SQL Server / MySQL, phpMyAdmin.
